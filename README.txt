Inventory Blacklist - Fabric Mod (Minecraft 1.21.1 / Java 21)
================================================================

Diese Version enthält alle korrigierten Java-Klassen sowie den funktionierenden GitHub Actions Workflow.

Anleitung:
1. Entpacke dieses ZIP-Archiv.
2. Ersetze den gesamten Inhalt in deinem GitHub-Repository durch diese entpackten Dateien.
3. Geh auf GitHub auf den Reiter 'Actions'.
4. Der Build startet automatisch und erstellt dir unter 'Artifacts' deine fertig kompilierte .jar-Datei!
